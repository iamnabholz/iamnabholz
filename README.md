### Design tools & plugins

**[Gridify](https://github.com/iamnabholz/penpot-gridify-plugin)**  
Generate line and dotted grids directly in Penpot.

**[Squircle](https://github.com/iamnabholz/penpot-squircle-plugin)**

**[Tints and Shades](https://github.com/iamnabholz/penpot-tints-and-shades-plugin)**

**[Starter Profile](https://github.com/iamnabholz/penpot-starter-profile-plugin)**

Penpot plugin to transform your designs into low-fidelity concepts.
